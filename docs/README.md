## 写作与清理

- 单个顶级标题；标题下写文档定位/对应版本/更新日期。较长文档带准确目录，日期YYYY-MM-DD。
- 状态只写项目记忆，规则写手册/性能，未来写计划，交付证据写变更记录；其他文档引用，不重复复制当前数字与待办。
- 编译、托管、产物同步、游戏加载/使用与保存重载分开；用户认可限当轮范围，未测边界不自动变施工任务。
- 过时版本状态、已撤销方案和重复报告从日常文档移除。旧正文可由Git或.tools/backups追溯，不为清理新建另一份默认读取的长历史。
- 修改后检查本地链接/锚点、版本/门禁/哈希和代码导航一致；代码交付按工程门禁，纯文档不用重复操作游戏。
