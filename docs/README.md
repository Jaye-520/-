# 文档入口

每次新会话先读项目记忆与长期计划，其余按任务查阅。文档分工固定：**记忆只放当前状态、未验收边界和下一步；手册只放结构、流程和防错规则；变更记录只放逐版证据与历史**，同一内容不三处重写。当前基线07.47，双玉简入口位置已固化进代码、F9自由移动已移除；构建/部署/版本号/工程一致性与死代码均有门禁守护。用户反馈功能正常不代表长期或全部特殊配置已验收。

| 文档 | 用途 |
| --- | --- |
| [项目记忆](../PROJECT_MEMORY.md) | 当前基线、当前实现、未验收边界、约束与下一步（唯一的“现在”） |
| [长期计划](LONG_TERM_PLAN.md) | 产品约定、阶段路线、字段与写入验收约定（唯一的“将来”） |
| [工程手册](ENGINEERING.md) | 代码导航、构建调试、官方资料、按主题的防错规则与按变更验证 |
| [功能范围](TRAINER_FEATURE_SURVEY.md) | 已同意首批范围、候选功能与调查来源（历史调查，非现状） |
| [变更记录](CHANGELOG.md) | 逐版结论、用户验收与历史证据（唯一的“过去”） |

只保留上述5份文档加本入口，共6份Markdown。普通迭代更新记忆和变更记录，不新增独立模板、报告或逐版说明。新增文档必须有不能被现有文档容纳的长期维护价值。

辅助资料：screenshots保留实测截图、用户标注反馈及模拟预览，文件名的feedback表示问题依据、layout表示GDI模拟，都不代表已验收。verification保留检查脚本，api-reference保留官方接口缓存（约11万个htm，未纳入Git）。最近一次用户反馈是07.40的[主界面错误位置](screenshots/entrance-map-feedback-07-40.png)与[NPC错误位置/新目标](screenshots/entrance-npc-feedback-07-40.png)。
